# Kunal Choudhary Portfolio

Responsive React + Vite portfolio for job and internship applications.

## Run locally

```bash
npm install
npm run dev
```

## Create a production build

```bash
npm run build
```

The deployable static website is generated in `dist/`. Upload the **contents** of `dist/` to the hosting document root.
